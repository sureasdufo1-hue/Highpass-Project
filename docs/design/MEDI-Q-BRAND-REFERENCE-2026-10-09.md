## 적용 및 경계

환자·의료진 웹, 모바일 헤더/인증 화면, 페이지 제목과 PWA 표시 이름에 적용. `brand` 스킬의 원본 비율·색상 유지 원칙을 사용했다. 기존 `public/ui/tokens.css`가 있으므로 별도 토큰 생성/강제 덮어쓰기를 하지 않는다.

내부 highpass/hipass 패키지·API·환경변수·DB·캐시 식별자는 호환성을 위해 유지한다. 이전 증적/승인 문서도 소급 개명하지 않는다. 기존 설치용 PNG/SVG 앱 아이콘은 아직 별도 전환 전이며 헤더 로고 적용과 구분한다.

앱은 제공 자료의 로그인→홈→영상 목록→공유 동의→QR→공유 관리 구성을 참조한다. 자료에 적힌 OAuth·보안금고·네이티브 생체인증은 디자인 참고이지 구현 증적/정책 변경 지시가 아니다. 아직 연결하지 않은 기능은 미연동 표시를 유지한다.

이번 변경은 표시 브랜드 적용이며 앱 전체 화면 재현 완료가 아니다. 배포·커밋·푸시하지 않는다. 신규 결과는 DRAFT / UNASSIGNED.
