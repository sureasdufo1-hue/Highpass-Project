# Privacy Impact Screening

검토 기준일: 2026-08-26

## 결론

하이패스는 의료영상과 진료 맥락 정보를 처리하므로 실서비스 전 개인정보 영향평가 또는 이에 준하는 사전 위험평가가 필요할 가능성이 높다. 현재 평가는 로컬 MVP 코드와 문서 기준의 사전 스크리닝이다.

| 질문 | 현재 답변 | 판정 |
|---|---|---|
| 민감정보 또는 건강정보를 처리하는가 | 실서비스 목표상 YES, MVP는 가상 데이터 | HIGH |
| 병원 간 제3자 제공 또는 위탁이 있는가 | 목표상 YES, 계약 미정 | HIGH |
| 대량 의료영상 전송이 있는가 | 범위 제한 전송 구현 | MEDIUM |
| 정보주체 권리행사 절차가 구현되었는가 | 동의 철회 일부 구현 | PARTIAL |
| 원본 DICOM을 클라우드에 지속 저장하는가 | Control Plane은 NO, Orthanc Data Plane | PASS |
| 연구·AI 목적 분리가 있는가 | 가명처리 시뮬레이션 | PARTIAL |
| 재식별 위험이 있는가 | DICOM UID, 가명 매핑, 영상 특성 | HIGH |
| 사고 통지 체계가 있는가 | runbook만 존재 | PARTIAL |

## 운영 전 필요 조치

- 실제 처리자 역할과 법적 근거 확정
- 동의서, 처리방침, 위탁계약, 국외이전 여부 확정
- 저장·전송·백업 암호화 실증
- 병원 IdP/MFA 및 재직 상태 연동
- SIEM/WORM 기반 감사로그 무결성
- 연구용 defacing 및 가명 매핑 분리 검증
