Platform Overview

CD 없이, 더 빠르고 안전한 의료영상 공유

하이패스는 환자의 명시적 동의를 중심으로 병원 간 CT, MRI, X-ray 등 의료영상을 안전하게 조회할 수 있도록 돕는 MVP 플랫폼입니다. Control Plane은 동의와 정책을 관리하고, Data Plane은 승인된 DICOMweb 범위만 전송합니다.

환자 동의 DICOMweb HL7 FHIR 단기 토큰 RBAC + ABAC 감사로그

Virtual PACS / Orthanc

Orthanc는 하이패스 MVP의 가상 병원 PACS 역할을 합니다.

Orthanc는 A병원에 보관된 샘플 DICOM 원본과 Study, Series, Instance 메타데이터를 제공하는 Data Plane 구성요소입니다. 하이패스 Control Plane은 원본 DICOM을 장기 저장하지 않고, 환자 동의와 단기 토큰 검증을 통과한 요청만 Gateway를 통해 Orthanc로 전달합니다.

01

가상 PACS 저장소

실제 병원 PACS 대신 샘플 DICOM을 보관하고 영상 목록 조회의 원천 역할을 합니다.

02

DICOMweb 조회 대상

Gateway가 QIDO-RS와 WADO-RS 흐름을 시뮬레이션할 때 Orthanc의 Study, Series, Instance를 조회합니다.

03

원본 분산 보관 검증

Control Plane DB에는 최소 메타데이터와 감사 정보만 두고, 원본 영상은 Orthanc/Data Plane에 남겨 분리 원칙을 확인합니다.

04

MVP 한계 표시

현재 Orthanc는 로컬 가상 PACS입니다. 실제 병원 PACS나 실제 환자 데이터에는 연결하지 않습니다.

Security Architecture

보안은 기능이 아니라 플랫폼의 기본 구조입니다.

환자 동의, RBAC + ABAC, 범위 제한 토큰, 감사로그를 하나의 흐름으로 연결해 Fail Closed 원칙을 유지합니다.

환자 동의 기반 접근

단기 접근토큰
