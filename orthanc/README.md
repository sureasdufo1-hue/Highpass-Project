# Orthanc Integration

`hospital-a-orthanc` is the virtual PACS for Hospital A in the HiPass MVP.

Current constraints:

- Orthanc is reachable from Docker services through `http://hospital-a-orthanc:8042`.
- Host ports are not published by default.
- `hospital-a-orthanc-seed` uploads synthetic DICOM instances on `docker compose up`.
- The Control Plane stores only metadata, consent, token logs, audit logs, and transfer logs. It does not persist original DICOM files.

Gateway access:

- Public client traffic should go through the Control Plane Gateway routes under `/dicomweb`.
- Gateway routes require a signed short-lived DICOM access token.
- The Gateway exposes DICOMweb-shaped MVP routes and calls Orthanc's internal REST API.
- Direct Orthanc access is internal to Docker for this MVP.

Sample data:

- Patient identifiers and names are virtual demo values only.
- Sample DICOM instances are generated by `scripts/load-sample-dicom.js`.
