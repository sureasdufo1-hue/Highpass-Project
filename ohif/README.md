# OHIF Integration

`hospital-b-viewer`는 B병원 Viewer 역할을 하는 OHIF 컨테이너입니다.

접속 주소:

- OHIF Viewer: `http://localhost:3001`

`app-config.js`는 A병원 Orthanc DICOMweb endpoint를 바라봅니다.

- QIDO-RS: `http://localhost:8042/dicom-web`
- WADO-RS: `http://localhost:8042/dicom-web`
- WADO-URI: `http://localhost:8042/wado`
